UI 落点 ↔ DSH 扩展点

这个原型按现有 DSH Web UI 的 Slot 体系设计，全部为「新增包 + 挂载到公开 seat」，不改布局包。

sidebar.panellist左侧 Projects 一级入口（图标 + 数量）→ main key projects 的 Projects 首页。
main: projectsProjects 首页：项目卡、新建项目、最近活动。全局面板（无会话绑定），参考 Plugins 页实现。
conversation项目工作台 = 协调者会话：复用现有 ui-conversation，不新写聊天壳。
conversation.header.leading面包屑：Projects / 项目名 / 项目对话；线程页显示 Projects / 项目 / 线程 #n。
conversation.session.header.actionsHeader 右侧：Threads 面板开关（带「需要你」圆点）、⋯ 菜单。
library.foldersLibrary 的文件夹是项目域内的组织层（folderId）；移动/重命名不改变不可变字节与引用 ID，线程只读。
conversation.chat.*线程卡 / 汇报卡 / 审批卡 / Suggested threads 卡片：走 Chat 的 tool view 与 turnTail 扩展（M3 美化；M2 先普通工具结果 + Overview 行）。
sidebarRightTabs右侧栏 tab type：project-threads（默认首个 tab）、project-library、project-settings；body 注册到 sidebar.right.pane.tab。
ctx.sidebarRight.openTab打开项目时自动打开 Threads tab；「需要你」圆点来自 pendingInteraction 投影聚合。
sidebar.workspaces.session.menu.item「从会话创建项目 / 移入项目」入口挂在现有会话行菜单上（M4）。
shell.overlay新建项目 / 删除确认 / 项目设置等模态层，复用现有浮层。
project domain + tools项目/线程/资料库/记忆数据来自新 projects storage domain；聊天里的卡片来自 project_* 工具结果与线程 report。
pendingInteractionThreads 的「需要你」= 审批 / 问题 / 失败 / 线程 report 的 needs 字段，不双写。
